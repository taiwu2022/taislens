# Photo Uploads

Put original or web-ready photos in these folders.

## Suggested folders

- `featured/` - homepage hero image and strongest selected photos
- `gallery/` - photos shown in the main gallery
- `archive/` - extra photos not shown on the homepage yet

## Naming

Use simple lowercase names with hyphens, for example:

- `london-01.jpg`
- `ucl-evening-01.jpg`
- `lake-district-01.jpg`

Avoid spaces and very long filenames.

## Web size

For the website, JPEG or WebP files around 1600-2400 px wide are usually enough.
Large originals can live elsewhere; this folder should contain versions intended
for publishing.
